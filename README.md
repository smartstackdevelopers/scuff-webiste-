# scuff-webiste-

## You Scuff We Buff — Premium UK Automotive Detailing & SMART Repair Platform

A modern, agency-grade web application and booking management system built for high-end automotive detailing, ceramic coatings, and mobile SMART repair services.

---

### 🚀 Key Features

- **Cinematic Public Experience:** 
  - Dynamic automotive video backgrounds and high-definition before/after transformation sliders.
  - 17 fully integrated public routes including dedicated hubs for Car Painting (`/car-painting`) and Car Maintenance (`/car-maintenance`).
  - Interactive multi-step online booking wizard with instant reservation reference generation.
- **Enterprise Operations & CRM:**
  - Complete lead generation, pipeline Kanban boards, and salesperson commission tracking.
  - Customer profile garage, booking history, and downloadable invoices.
  - Staff bay workflow with mobile technician dispatch and task management.
- **Design System:**
  - Luxury automotive dark palette (`#07080A`, `#0C0F15`, `#11151E`, `#151922`).
  - High-visibility brand green (`#48C84D`) accents and warm priority amber (`#F59E0B`).
  - High-contrast typography (`Bebas Neue` display headings + `Manrope` body).

---

### 💻 Tech Stack

- **Framework:** React 19 + Vite 6 + TypeScript
- **Styling:** Tailwind CSS + Radix UI + Framer Motion
- **Icons:** Lucide React
- **Multimedia:** Native HTML5 Video Engine + Optimized MP4/WebM Assets
- **Routing:** React Router v6

---

### 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript type check
npm run type-check

# Build for production
npm run build
```
